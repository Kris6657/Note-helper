# 笔记生成提示词

把课件 PDF 变成 Note-helper 能用的笔记。先抽取带页码的文本，再按下列格式生成笔记。示例命令从项目根目录运行，输入仅使用自制演示。

```
课件 PDF ──extract_pdf.py──▶ moduleN_raw.txt ──本提示词──▶ notes.md
           （逐页抽文本，             （带 ===== PAGE n ===== 分隔）
             自动打页分隔）
```

---

## 这个工具的格式约束（决定了笔记该怎么写）

| 工具做的事 | 对笔记的要求 |
|---|---|
| 把**叶子标题**当「掌握点」（复习时逐条打钩的清单） | 标题层级 = 知识颗粒度。「议程」「为什么要学」「小结」这类讲稿装置不能进标题 |
| 按**页码递增**算跳转与同步滚动 | 内容顺序必须跟着课件页序，不能为了归类而大搬家 |
| 按**块**标注（段落 / 列表项 / 表格行） | 一个块别太长；超过 5 行的连续内容就拆成列表或升标题 |
| 表格**按行**切块 | 对照关系一律用 Markdown 表格，一行一个考点 |
| 纯文本渲染，**没有图** | 图片页要先渲染成图读一遍再决定；确实读不出内容的才把页码列出来 |

最容易踩的是第一条。课件是为**现场讲**写的，它的推进顺序里混着大量讲稿装置（议程、动机铺垫、回顾、小结）。这些东西照搬进笔记**不会报错**，但会被算成「要掌握的知识点」——最后把你的复习清单污染成一份讲稿目录。

所以整份提示词的核心就一句话：**顺序跟课件，结构跟知识。**

---

## 第一步：抽文本

```powershell
python tools/extract_pdf.py "examples/演示课程/Module 1/slides.pdf" module1_raw.txt
```

`extract_pdf.py` 会输出 `PAGES=总页数` 和每页的 `===== PAGE 7 =====` 分隔，**这个分隔就是页码的唯一来源**，AI 只能从这里取页码。

> 这一步用 `pypdf`。可选工具需要 Python 3.10+；依赖准备见 README 的 `requirements-tools.txt`，阅读器本身不需要它。

抽完先看最后打印的 `empty_pages=[...]`——这些是**文字层为空的页**。
它们通常不是空页，而是一整页图版正文（图标 + 说明段），直接跳过就是真的丢内容。
把这些页号交给 `render_pages.py` 渲染成图，再用图像读一遍：

```powershell
python tools/render_pages.py "examples/演示课程/Module 1/slides.pdf" 1 2 3
```

它会逐页打印 PNG 的路径。判断规则见下面第二部分第 15 条。

Page 多的时候先加 `--montage` 拼成一张图筛一遍（分隔页一眼就露馅），可疑的再去掉该参数放大读：

```powershell
python tools/render_pages.py "examples/演示课程/Module 1/slides.pdf" 1 2 3 --montage
```

> `render_pages.py` 用 `pypdfium2`，拼图模式另需 `Pillow`；与抽文本工具共用 `requirements-tools.txt`。

---

课件、笔记或抽取文本发送给外部 AI 前，请先确认拥有相应权限；本地阅读器不会代为上传。

## 第二步：把下面的提示词连同 `moduleN_raw.txt` 一起发给 AI

> 下面的整段**可以直接复制**，粘到任何对话 / 第三方 LLM 都有效——它自带全部要求，不引用这个项目里的任何文件。
> `{课程名}`、`{模块号}`、`{模块主题}` 自己替换。

```text
你在帮我做一门大学课程的复习笔记。下面会给你一份课件抽取出来的纯文本，
每页之间有 "===== PAGE n =====" 分隔。

━━━ 第一部分 · 内容怎么组织（最重要，先读这一节）━━━

一句话原则：顺序跟课件，结构跟知识。

▸ 顺序跟课件
  内容的先后顺序必须与它在课件里出现的页面顺序一致，页码单调递增。
  不要为了让同类内容聚在一起，就把后面的内容挪到前面——这个工具按页码
  递增来算跳转和同步滚动，顺序一乱，定位就全错。

▸ 结构跟知识
  标题层级按知识本身的关系重组，不要照搬课件的讲述顺序。课件是给"现场讲"
  用的，它的推进顺序里混着大量讲稿装置。下面这些一律不要写成标题，也不要
  单独成节：
    · 议程页 / 目录页 / 本节要点 / "我们要讲什么"
    · 动机铺垫（为什么要学、为什么这对你重要）
    · 回顾页（上次讲了什么、快速回顾）
    · 过渡页、小结页、致谢、问答环节
    · 同一个内容课件讲了两遍 → 合并成一处，页码并列写：（P48、P53）
  如果一整页只有这类内容，就不进笔记；如果它夹着实质内容，只取实质内容，
  页码照标。

▸ 标题层级 = 知识的颗粒度，一层一层来，不要跳级
    ##     一个知识板块        例：偏差的类型
    ###    一个考点            例：数据偏差 / 算法偏差 / 人为偏差
    ####   一个考点的内部分层   例：定义 / 支持理由 / 反对理由 / 适用条件
  整份笔记的颗粒度要一致，不要一部分用到三级、另一部分只有一级。

▸ 「定义 / 支持 / 反对 / 前提 / 适用条件 / 例子」这类结构性分层，必须用
  #### 标题，不许写成 **加粗**。
  理由：这个工具按标题层级计算「掌握点」（复习时逐条打钩的那份清单），
  加粗不算标题——用了加粗，一整节三十行就只算一个掌握点，没法逐点勾。

━━━ 第二部分 · 硬性格式要求，逐条遵守 ━━━

1. 页码标记。每一个标题、每一个知识点段落，都必须紧跟一个页码标记。
   标记只有三种写法，全部使用全角括号和全角标点：
     · 单页：      （P7）
     · 连续范围：  （P7–P15）        ← 中间是「–」（U+2013），不是减号
     · 不连续多页：（P11、P14）       ← 中间是「、」
   不要写 (P7)、P7页、[P7]、P.7 等其他形式。

2. 标记的位置。页码标记必须紧跟在它所描述的那段内容之后，写在同一个段落或
   标题内，绝不能单独占一行。例如：
     ### 什么是正义（P5）
     **核心命题（P7）**
     > 引文……（P7）

3. 层级结构。用 # / ## / ### / #### 组织，最多到四级（划分方式见第一部分）。
   标题本身也要带页码，写这一节的起止范围，例如：
     ## 1.1 哲学视角（P5–P21）

4. 页码的继承。同一个标题下的列表项，如果和标题在同一页，可以省略页码；
   一旦跨页就必须标出来。不要给每一行都堆页码，那会让笔记没法读。

5. 页码必须来自原文的 PAGE 分隔，按内容实际所在页填写，不要凭感觉估。

6. 不许增补。只整理课件里写到的东西。你的理解、举例、延伸一律不要写进正文。
   我另有地方放批注。

7. 引文。课件里加粗或点睛式的原话，用 > 引用块保留，并在后面带上页码。

8. 表格。课件里的对照关系用 Markdown 表格还原；
   如果同一组内容课件给了两个版本，就并排成两列说明。

9. 跨模块引用。如果我提到别的模块，写成 [[Module 2]] 这种双链写法，
   不要写成「参见 Module 2」这种自然语言。

10. 正文里不要出现"关于这份笔记本身"的内容。具体来说，不要写：开头的全课
    路线图、末尾的知识骨架树、讲义的结构特征与抽取说明、与相邻模块的差别、
    反复出现的句式、受众预设。这个工具自己会用标题层级和掌握点清单把结构
    显示出来，重复一遍只会把「掌握点」污染成「讲稿目录」。

11. 末尾的说明块。确实转不成文字的页（纯装饰插画），在正文最后用一段引用块
    列出来——用引用块而不是标题，免得它被算成一个知识点。格式：
      > 注：P26 为纯装饰插画，需回看原课件。
    只有标题没有正文的页，同样在这里注明。
    ⚠️ 往这里扔任何一页之前，必须先按第 15 条把它渲染成图看过，确认页上真的
    没有可用文字。这里不是图省事的去处。

12. 不要输出 HTML，不要寒暄，不要解释你的做法。直接给 Markdown 正文。

13. 略去的页要留下交代。凡是按第一部分「结构跟知识」剔除掉的页（议程页、目录页、
    小结页、回顾页、过渡页、分隔页、致谢页），都要在它**原本所在的位置**补一条
    引用块，只标页码与类型，不要抄它的内容。格式：
      > 未入笔记：P44 小结页、P45 分隔页、P46 本节议程页。
    目的：让页码序列读起来是连续的，而且任何一次页码跳跃都能看出是「有意略去」，
    而不是「没提取到」。
    开头那条要覆盖正文之前的所有页，末尾那条要覆盖正文之后的所有页。

14. 路线图按课件自身情况决定，不要一律加、也不要一律不加。
    · 课件**自带**议程页／小结页／回顾页 → 不另写路线图。这些页按第 13 条留一条
      交代即可；如果某页整页都是议程内容、对看清全课结构有用，可以把它的**原文**
      整段放进那条引用块里（仍然不占标题）。
    · 课件**不带**这些、而且讲述顺序散乱 → 才在正文最前补一份路线图，同样用引用块
      呈现、不占标题，并在其中标出它对应哪些页。
    判断标准就一句：**课件自己给过就不要自己编。**

15. 文字层为空的页，先渲染成图看一眼再下结论，不要直接写「无文字层」了事。
    很多「空页」其实是一整页图版正文（图标 + 说明段，甚至整页的定义或图表说明），
    丢掉就是真的丢内容。
    · 有实质内容 → 按正常考点写进笔记，页码照标，和其他页一视同仁。
    · 只是装饰插画、或图上文字确实无法辨读 → 才按第 11 条列进末尾说明块，
      并写明是哪一种。
    实现方式见第一步的 `render_pages.py`。
```

## 校验：生成完自查这几条

| 检查项 | 怎么看 |
|---|---|
| 页码标记写法统一 | 搜 `(P` 半角括号，应该搜不到；搜 `（P` 应该很多 |
| 没有孤立页码行 | 不该出现整行只有 `（P7）` 的情况 |
| 标题带页码 | 每个 `##` / `###` / `####` 标题末尾都该有 `（P..）` |
| 跨模块引用是双链 | 搜 `Module`，出现的应该是 `[[Module N]]` |
| 没有增补内容 | 通读一遍，确认没有你自己的发挥 |
| **没有讲稿装置** | 标题里不该出现「议程 / 为什么重要 / 小结 / 收尾 / 回顾 / 过渡」 |
| **分层用的是 `####` 不是加粗** | 搜 `**定义**`、`**Case For**`——应该改成了 `#### 定义` |
| **正文里没有元信息** | 不该有「全课路线图」「知识骨架」「抽取说明」这类小节 |
| **略去的页有交代** | 正文里每一次页码跳跃处，都该有一条 `> 未入笔记：…` 引用块 |
| **空页已核过** | `empty_pages` 里的每一页，要么已写进正文，要么已列进末尾说明块 |
| **全篇页码单调** | 不能只看相邻两个标题——**父子标题之间也算** |
| **末尾说明块形式对** | 应该是 `> 注：…` 引用块，不是标题 |

逐页核对标题、正文与页码顺序，并对照课件检查未覆盖页。本仓库未提供自动笔记质量审查脚本，不能将命令运行成功当成内容准确的证明。

**最后一关（最直接）：** 打开工具右栏顶部的掌握点下拉、选「最细」。那份清单应该像一份**考点清单**——如果出现「本节议程」「讲义收尾」，说明结构还是被讲稿带跑了。

生成得不好，直接把这份提示词连同 raw.txt 再发一次，并指出哪一条没遵守——比手工改快。
